# LU3IN025-Gale-Shapley
Projet d'Intelligence Artificielle et Jeux (LU3IN025) de Sorbonne Université. Implémentation en Python de l'algorithme de Gale-Shapley pour l'affectation stable des étudiants en Master Informatique. Inclut des analyses de complexité et l'utilisation de Gurobi (PLNE) pour l'optimisation de l'équité.
